# Coleção Carros (Mattel 1:55)

Site estático: abra `index.html` (ou sirva a pasta com `python3 -m http.server`).

- `assets/data.js` – elenco de cada filme (edite para adicionar/ajustar carros; `1` na 5ª posição = existe Mattel).
- Fotos: o site busca a imagem de cada personagem nas wikis de Carros (Fandom) pelo navegador. Para usar uma foto sua, salve em `img/<nome-do-carro-em-minusculas-com-hifen>.jpg` (ex.: `img/lightning-mcqueen.jpg`).
- O progresso fica no `localStorage`; use Exportar/Importar para backup.
